# 青少年创客活动教案建议

面向小学高年级～高中入门。每课约 60–90 分钟。不必一次讲完所有传感器。

## 课前准备（教师）

- [ ] 每组：1 块 ESP32-C3、USB 线、手机（装 phyphox）
- [ ] 预烧录 `01_hello_phyphox`，或教学生自己烧录
- [ ] 打印/投影 [hardware.md](hardware.md) 接线图
- [ ] 备用板 1～2 块；检查教室电源与蓝牙干扰

## 第 1 课：认识「无线传感器」（Hello）

**目标**：完成板子 ↔ phyphox 连接，会读曲线、会导出。

1. 演示：手机打开 phyphox，连接 `Maker-C3-Hello`
2. 学生操作：找到设备、开始测量、缩放坐标轴
3. 讨论：横轴是什么？纵轴为什么会波动？
4. 选做：导出 CSV，用表格软件画一张图

**成功标准**：每组至少拍一张「正在测量」的屏幕。

## 第 2 课：模拟量与控制变量

**固件**：`02_analog`  
**器材**：电位器或光敏分压

**探究问题示例**

- 旋钮转角与 ADC / 百分比是否近似线性？
- 遮光程度与读数如何对应？怎样定义「暗 / 亮」阈值？

**活动流程**

1. 接线 → 烧录 → 连接 `Maker-C3-Analog`
2. 每人记录 5 个稳定读数（不同旋钮位置或遮光条件）
3. 小组画「条件 → 读数」表，讨论误差来源（接触不良、手抖、环境光）

## 第 3 课：距离与运动（超声波）

**固件**：`05_ultrasonic`  
**注意**：ECHO 电平转换（见硬件文档）

**探究问题示例**

- 缓慢靠近时，曲线是否平滑？突然挥手会出现什么？
- 最小可靠距离大约是多少？超过某距离为何不稳定？

**延伸**：用纸板做「车道」，测量模型车通过两定点的时间差，估算平均速度。

## 第 4 课：温湿度 / 天气瓶

**固件**：`03_dht22` 或 `04_bme280`

**探究问题示例**

- 对着传感器呵气，温度和湿度谁先变？
- 密封袋里放湿纸巾 vs 干燥剂，曲线有何不同？
- （BME280）楼层变化时气压差能否被测到？

提醒：DHT 约 2 秒才更新一次，不要以为程序卡死。

## 第 5 课：综合创客挑战（套件）

**固件**：`07_maker_kit`

给学生一个开放任务，例如：

> 设计一个「课桌环境监测站」：同时关注光照/遮挡（模拟或 BH1750）、人体靠近（超声波）、空气闷热（温湿度）。记录 3 分钟数据，用三句话解释现象。

评价维度建议：接线正确、数据可复现、解释合理、合作与安全。

## 课堂管理小贴士

- 设备命名已带前缀 `Maker-C3-`；多组同时做时，可在 `board_pins.h` 改前缀或在 `begin("教室A-01")` 写死组号，避免连错
- 先要求「串口有数」，再查手机连接，排错更快
- 强调用电安全：勿短路 5V/3V3；超声波分压不要省

## 与课标/素养的对应（简述）

| 素养 | 本套件中的体现 |
|------|----------------|
| 科学探究 | 提问 → 测量 → 证据 → 解释 |
| 工程思维 | 接线、电平、采样周期、误差 |
| 数字化学习 | BLE 采集、图表阅读、数据导出 |
| 合作交流 | 分组测量与汇报 |
